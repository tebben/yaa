## Milestones

Each milestone ends on something usable, and the first product-defining slice, parallel agents in worktrees, lands at M2.

M0 answers the riskiest open questions before the plugin API is built in M1. Milestones are ordered, not dated, and the plugin API grows with the built-in plugins that use it.

The concrete task breakdown lives in `docs/plan.md`, which includes workflows (manual workflows and the runs panel in M5 after worktrees and chat, sensors and unattended runs after the PR plugin and notifications).

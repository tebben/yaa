# 0003 Out of scope for the first release

Status: decided, 2026-11-26.

Decision: the first release has no arm64 build, no plugin marketplace, no accessibility work, no cost budgets and no auto-update. Linux x64 only.

Consequences: users download new AppImage, deb or rpm files from the release page; the app may show a notice when a newer version exists. Each item can be reopened with a new decision file.

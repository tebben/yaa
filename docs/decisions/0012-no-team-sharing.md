# 0012 No team-sharing features

Status: decided, 2026-11-26.

Decision: yaa is built for one user. There are no features for sharing workflows, unattended-run rules, settings or setup steps within a team.

Consequences: per-project files (workflows, worktree setup) may still be committed with a repository, but the app adds nothing on top, such as shared policies or merge rules. Can be reopened with a new decision file.
